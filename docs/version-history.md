# Version evolution

## Earlier competition version

The earlier local version explored contract search, a contract workspace,
submission review and community interaction. Its competition documents,
screenshots, account data and release archives are not inputs to the public
2.0 demonstration.

## ContractSearch 2.0

2.0 focuses on contract retrieval, source provenance, a bounded Agentic RAG
control plane, and an integrated contract workspace. Community, messaging and
administrative-review pages from the earlier version are not present in the
current frontend. 2.0 should not be described as a strict superset of every
earlier feature.

## Public repository preparation

The current revision adds a synthetic demo/bootstrap path, reproducible
configuration, clearer service boundaries, extracted frontend modules,
third-party attribution, privacy checks and a distinction between historical
reports and current validation. See the [changelog](../CHANGELOG.md).

A version tag or GitHub Release should identify a checked commit and its known
limitations. Historical phase numbers inside Agent records describe delivery
stages; they are not public semantic-version releases.
